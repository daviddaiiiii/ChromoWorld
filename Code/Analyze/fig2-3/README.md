# Fig2-3: ChromoPix segmentation and evaluation

Run from the release root. Use the processed PNG images and matching polygon
TXT labels in Dataset/2D; robustness images are generated by the provided
script and are not part of the packaged train/test dataset.

```bash
python Code/Analyze/fig2-3/get-polygon_PNG2TXT.py --gpu_id 0
python Code/Analyze/fig2-3/get-metrics_TXT2CSV.py
python Code/Analyze/fig2-3/create_fig2_3_demo.py \
  --pred-dir Code/Analyze/results/predictions/ChromoPix
```

The defaults locate ChromoPix and DINOv3 weights in Checkpoint and save
predictions/reports in Code/Analyze/results. Inference queries all 24 classes
at 512×512 and restores mask probabilities to native image size before
extracting polygons. Classes are 0–21 for chromosomes 1–22, 22 for X, and 23
for Y. Evaluation defaults to ChromoPix; supply other component TXT folders
with --baseline_path and choose their class filters with --class_configurable.
The historical ChromoPix metric filters predictions by GT-present classes.

The curated panels in demo_outputs are Banding_5x3.png and FISH_5x3.png:
five samples as rows, and input / GT / 24-color prediction as columns.
create_fig2_3_demo.py selects the same ten stems from the test set. Unlabelled
FISH GT instances use neutral gray.

get-visualize_TXT2PNG.py and visualize-mask-overlay_TXT2PNG.py offer per-image
polygon views. test-robustness_TXT2PNG.py generates synchronized perturbations
of image/label pairs; rerun the inference entry on its image outputs and the
evaluator on the corresponding transformed labels to reproduce Fig3 metrics.

The underlying model training and standalone checkpoint evaluation entry
points are documented in ../../ChromoPix/README.md. All examples resolve
relative paths from the release root, including when launched from another
working directory.
