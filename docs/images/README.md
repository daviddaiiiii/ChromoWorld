2. `chromopix.png`: sparse FISH identity clues and ChromoPix predictions.
3. `morphology-alphabet.png`: cross-state chromosome morphology organization.

transparency. The original presentation remains unchanged and is not uploaded.

them here. Preserve the 24-class chromosome palette in the scientific figures.
